# Sketch.io

**Sketch.io** is an interactive web-based drawing application built with **TypeScript** and the **HTML5 Canvas API**. It lets users create, drag, customize, and manage simple geometric shapes in an intuitive visual environment.

## Features

- **Shape Creation**  
  Add circles, squares, or triangles instantly using the sidebar menu.

- **Drag & Drop Manipulation**  
  Click and move shapes smoothly across the canvas.

- **Color Customization**  
  Change any shape’s color using the integrated color picker.

- **Layer Management**  
  Clicking a shape brings it automatically to the top (foreground).

- **Adaptive Canvas**  
  The canvas resizes dynamically to match the browser window.

- **Clear All**  
  A dedicated *Erase* button wipes the canvas instantly.

## Technologies Used

- **TypeScript** – for structured, object-oriented logic  
- **HTML5 Canvas API** – for efficient graphical rendering  
- **CSS3** – for the UI and sidebar styling

## How to Run

### **1. Clone the repository**
```bash
git clone https://github.com/catalina-constantin/Sketch.io.git
cd Sketch.io
```
### **2. Install dependencies**
Make sure you have *Node.js* installed, then install the *TypeScript* compiler:
```
npm install -g typescript
```
### **3. Compile the TypeScript source**
```
tsc
```
### **4. Run the project using VS Code**
Install the Live Server extension. Right-click index.html file and select "Open with Live Server".
